## 状态与交互

| 状态 | 统一约定 |
|---|---|
| 默认与按下 | 可操作对象保持明确入口，点击及时反馈；静态内容不增加无意义的点击行为。 |
| 悬停与焦点 | 不依赖 hover 暴露触屏操作；按钮、链接保留键盘焦点。文本、搜索、多行文本和日期字段不显示蓝色外描边；输入和选择控件通过原有边线与浅灰背景反馈。 |
| 选中 | 业务分类与底部导航使用品牌红；顶部视图使用白底、黑色加粗；不能仅靠颜色传达选中状态。 |
| 禁用 | 阻止动作，不将禁用项加入可激活操作；加载和禁用分别表达。 |
| 加载 | 阻止重复提交，浅底转圈使用红色渐变；轻提示加载与任务生命周期绑定，耗时操作提供取消。 |
| 错误与恢复 | 就近说明原因，保留输入与可恢复路径；不将空数据伪装为加载失败。 |
| 完成与空状态 | 文字轻提示约2.5秒消失；需要决定的操作使用 Dialog，空状态说明原因并提供下一步。 |

- 浮层打开后限制背景操作并管理内部焦点；支持的关闭方式包括明确按钮、遮罩和 Escape，关闭后回到触发入口。
- 所有手势提供按钮或键盘替代：分页、缩放、更多、刷新等入口必须可访问。
- 减少动态效果设置下，停止非必要旋转和动画，使用静态文字表达当前状态。
- 320 / 375 / 430px及横屏均检查可读性、滚动和至少44×44 px点击热区。
