# 广智新 App 设计规范

适用于 App 的基础样式、9 类 71 项组件及交互行为。尺寸以375px设计基准为准。

## 布局与页面背景

- 设计基准为 **375 px**。手机按可用宽度等比适配。
- 工作台与门户首页卡片左右各 **10px**，基准宽 **355px**；模块间距约 **10px**。常规页面内边距 **16px**；IM和“我的”模块（含二级及更深页面）左右各 **10px**，卡片内部仍为16px；弹窗正文 **20px**。
- 普通页面背景 **#F2F1F5**；AI 对话背景 **#F8FAFE**；内容卡片 **#FFFFFF**；关闭圆底 **#F5F6F8**。
- 工作台与门户保留现有粉色装饰头图；智能体、技能页使用普通背景。
- 常用功能与系统导航采用 **rgba(255,255,255,0.7)** 背景和 **12px** 背景模糊。透明度只作用于卡片背景，文字和图标保持不透明。
- 页面内容独立滚动，底部导航和 AI 输入栏固定在底部并保留安全区。列表切换后按实际内容撑开，空状态不保留大块固定高度。

## 字体层级

所有尺寸以 375px 设计基准为准。顶部导航标题使用 18/26、600 字重；通用页面标题沿用下表的 400 字重。徽章计数胶囊另使用 12/16、400，见徽章组件说明。

| 角色 | 字号 / 行高 | 字重 | 颜色 |
|---|---|---|---|
| 页面标题 | 18 / 26 | 400 | #03091B |
| 首页模块标题 | 16 / 24 | 600 | #03091B |
| 弹窗标题 | 18 / 26 | 600 | #03091B |
| 顶部选中视图 | 16 / 24 | 600 | #03091B |
| 列表标题 | 16 / 24 | 400 | #03091B |
| 正文 | 14 / 22 | 400 | #03091B |
| 功能名称 | 13 / 20 | 400 | #4E5969 |
| 次级内容 / 辅助说明 | 12 / 18 | 400 | #4E5969 / #878B99 |
| 角标数字 | 10 / 14 | 400 | #FFFFFF |

首页模块标题使用16/24、600字重，配橙色渐变竖条；弹窗标题使用18/26、600字重。文字容器应容纳完整行高，长标题自然换行。

## 当前 App 业务组件

- **系统导航、我的系统、全部系统**：统一 5 列；首页一页 5 个，黑红线性图标 34px。
- **常用功能**：4 列 × 2 行、一页 8 个，彩色图标 34px；横向滑动与分页按钮同步。
- **入口分页**：选中红色12×3px胶囊，未选中灰色6×3px；视觉间距4px，均为全圆角，整体居中。
- **海报**：5 个真实案例，基准 355×134px，16px 圆角，白色圆点指示，支持左右滑动及对应案例详情。
- **底部导航**：小新AI、工作台、广新门户、IM、我的；22px 图标、13/20 文字。小新AI复用专属形象，选中工作台和门户为红色实心，选中IM为红色 Hi 图标。
- **每日简报**：详情放在标题右边，历史在最右边，两个图标均 16px；AI 帮写感谢按钮主体高32px、胶囊圆角，点击热区至少44px。
- **AI 输入栏**：白底、16px 圆角；相机和加号图标 18px，在30px浅灰圆底居中，点击热区独立扩大。
- **管理关注**：已关注主题 / AI订阅双视图；描边卡片、红色星标、编辑入口；AI描述最多4000字，生成后检查、编辑并保存关注。

文本输入、搜索、多行文本和日期时间控件点击/聚焦时不显示蓝色外描边，保留原有边线与浅灰底反馈。

## 控件高度

- AI智能资讯、集团综合资讯、AI热点追踪的分类胶囊统一28px高；相邻分类视觉间距16px，滚动导航同步使用。
- AI 输入栏上方选项按钮：34px。
- 管理关注页签容器：36px，四周内间距2px，内部选项32px；关注、已关注、编辑按钮：28px，全圆角；生成与保存按钮：36px。
- 统一待办的待办／已办／消息分类使用28px胶囊、16px间距、44px操作热区，选中为浅红底红字；首页待办列表不显示状态标签。
- 单行输入框、搜索框、选择器及标签选择按钮：40px；多行文本按内容及行数设置高度。
- 提示气泡主体：32px，不含8px三角；轻提示：至少48px，文字、加载、信息、成功、警告、错误六种效果；顶部通知：40px、通栏无圆角，使用语义浅色底。
- 确认 Dialog：基础操作栏48px；圆角确认按钮主体36px、点击热区44px。动作面板：选项至少56px，取消按钮52px。

## 弹窗与触摸

业务详情弹窗顶部22px圆角；标题左边距20px，18/26、600字重，标题栏最小66px，**没有底部分割线**。长标题允许换行。轻量确认 Dialog 使用16px圆角、320px基准宽，标题居中18/26、600字重，具体见确认弹窗规范。

关闭按钮：30px浅灰圆底、20px X图标、44×44px操作热区，圆底距顶部和右侧各12px。业务底部弹层遮罩为 #131928、40%透明度及2px背景模糊。

视觉尺寸与触摸热区分别定义。常规交互目标至少44×44 px，窄屏缩放后仍须保持规定热区。紧凑业务组件以实际样式展示，逐屏验收热区；不通过单纯放大图标代替热区。保留键盘、分页按钮、关闭按钮等手势替代操作及减少动态效果支持。

## 智能体附件

- **添加方式**：输入栏加号展开本地文件、云盘、聊天文件、照片、拍摄五个入口；面板在白色输入卡片下方独立展示，间距10px，去掉数量栏、收起箭头和容量说明；采用五列等分布局，图标24px、白底50px圆角容器，图文间距7px，功能文字12/18；移动端拍摄调用后置相机，桌面端使用系统文件选择器。
- **容量**：最多5个附件，单个不超过20MB；重复、空文件、超限和读取失败使用红色12/18提示，保留已添加文件。
- **文件卡片**：白底、1px浅灰描边、12px圆角；文件名14/22主文字，大小及状态12/18辅助文字，来源图标14px；紧凑状态显示两张卡片，点击红色“附件 n/5”展开完整列表，列表支持滚动、逐项移除及确认清空。
- **内容与状态**：文本附件读取正文，图片支持预览；未支持的文档明确标注“仅附件，未解析”，读取或文本解析失败显示红色错误并支持重试；不模拟服务器解析完成。
- **选择与预览**：云盘支持文件夹和面包屑导航，聊天文件支持搜索；选择控件18px、4px圆角，选中红底白勾；确认按钮为橙红渐变，取消按钮为中性灰底；弹层标题18/26、600字重，关闭按钮沿用规范。
- **保存与发送**：附件二进制保存在本机IndexedDB，草稿刷新可恢复；已发送附件保留卡片与预览下载入口。当前演示未连接附件分析服务，发送后明确告知此限制。

## AI 草稿与选择交互

- AI头部导航高52px，返回、历史记录、新建对话使用40px白色圆底与至少44px操作热区；标题居中18/26、600，下方增加灰色12/18“内容由AI生成仅供参考”。新建对话沿用历史记录中的新建入口，开启空白会话并保留最近记录。
- 首页最近记录和热门问答各最多显示3条；最近记录序号统一使用灰色辅助文字，热门问答保留前三名强调色。
- 热门问答、最近记录和技能树问题均先填入输入框，保留可编辑草稿，点击发送后再提交；提示词和摘要模板沿用相同逻辑。
- 输入区始终白底，正文与占位文字在上方左对齐，使用14/22正文；底部一行放置加号、语音按钮，有文字或附件时同时显示发送按钮。正文自然换行并随内容增高，达到150px后内部滚动；Enter换行，发送按钮或Ctrl/Command+Enter提交，中文输入法组合期间不提交。
- 上传或选中的文件先在输入框上方展示；知识库文档确认后显示名称与移除入口，PPT模板显示封面缩略图、名称与移除入口。选择操作不自动发消息或生成文档。
- 智能摘要“联动知识库”右侧使用34×20px开关，16px白色圆钮，关闭灰色、开启品牌红；整项保持至少44px操作热区，支持点击及Enter/Space切换，并以aria-checked表达当前状态。
- 智能写作知识库使用白底弹窗，支持通用、组织、团队、个人范围、层级导航、搜索与文档预览；取消保留原选择，确定后应用到草稿。
- 技能树为白底，领域与类别固定在问题列表上方，列表独立滚动，分页固定在底部；问题无分割线。类别使用28px高胶囊、16px视觉间距和至少44px操作热区，未选中浅灰底，选中浅红底红字。
- AI回复内容卡片使用白底，不添加背景阴影。

- AI首页智能体轮播左右各保留16px边距，滑动至首尾时不再留出居中空白；默认第二张居中，保留卡片弧形、倾斜效果与滑动吸附。

- 选择智能体后，隐藏AI首页欢迎语、智能体轮播和最近记录／热门问答；导航和智能体输入区保留。移除智能体后恢复首页内容，已输入的草稿保留；已有对话继续展示。

## 知识库节点双入口

- 名称、本级文件、下级固定三列；文件夹与数量独立点击后查看当前节点的文档，右侧箭头只进入下级列表，不同时触发文件操作。
- 本级文件数量按实际文档去重计算，包含当前节点直属知识库的文件，不包含更深的组织或团队后代；没有下级时保留列宽并隐藏箭头，零文件显示0并可查看空状态。
- 列表行70px，名称16/24，文件数量13/20，列标题12/18；团队图标32px浅青底，文件夹红色，箭头灰色；文件与下级之间使用18px高浅灰竖线，点击热区至少44px。
- 知识库弹窗和完整页面共用列表组件，保留范围切换、搜索、面包屑、预览、取消和确认选择。长名称省略，操作列始终对齐。
- 智能写作输入区点击发送后直接进入对话，不再打开独立的写作模板／要求／最近文档中转页；选择提示词仍先填入可编辑草稿。

## 组件规范

9类、71项组件，按用途、视觉、状态、无障碍与边界行为说明。

### 1. 基础原子

沿用品牌色、字体与系统图标，补齐尺寸与层级。

| 组件 | 英文 |
| --- | --- |
| 图标 | Icon |
| 弹窗标题与关闭 | CloseButton |
| 圆角 | Radius |
| 阴影 | Shadow |
| 间距 | Spacing |
| 分割线 | Divider |
| 骨架屏 | Skeleton |

#### 图标（Icon）

- **用途与选择**：表达搜索、日程、消息等明确动作；陌生图标配文字说明。
- **结构与视觉**：首页搜索图标 #03091B；系统入口使用黑红线性图标，34px；常用功能使用 34px 彩色图标。导航 22px，日常操作 20–24px，简报详情和历史 16px，AI 输入栏相机和加号 18px；视觉图标与触摸热区分别定义。
- **状态与交互**：可点击图标提供按下、聚焦和禁用反馈；纯装饰图标不响应。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：资源缺失时保留文字名称；不得以颜色或图标作为唯一状态信息。

#### 弹窗标题与关闭（CloseButton）

- **用途与选择**：关闭弹窗、详情和底部面板，位置与样式全 App 统一。
- **结构与视觉**：业务详情弹窗标题统一为 18px/26px、600 加粗，左对齐、左边距20px，标题栏至少66px高且无底部分割线；长标题换行。关闭按钮统一：30px 浅灰圆底 #F5F6F8、20px X 图标 #878B99、44×44px 点击热区；圆底距弹窗顶部与右侧各 12px。
- **状态与交互**：点击关闭按钮、允许的遮罩或 Escape 关闭；有未保存内容时先确认。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：长标题自动换行；关闭入口保持可见，关闭不误触背景。

#### 圆角（Radius）

- **用途与选择**：按输入、卡片、弹层和胶囊层级选用圆角。
- **结构与视觉**：输入控件 8–10px；应用目录卡片、首页卡片、海报、AI 输入栏与确认 Dialog 使用16px圆角；轻提示12px，顶部通知无圆角；底部弹层顶部22px，感谢按钮和胶囊切换使用全圆角。
- **状态与交互**：圆角只表达形状；不额外增加悬停或选中行为。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：图片与容器圆角一致；内容裁切不能截断焦点轮廓。

#### 阴影（Shadow）

- **用途与选择**：区分普通内容、悬浮操作与浮层的空间层级。
- **结构与视觉**：列表卡片以边线分层，悬浮操作与弹层使用阴影，避免堆叠。
- **状态与交互**：弹层出现时配合遮罩；普通卡片不因点击永久增加阴影。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：避免多个阴影叠加；高对比度环境仍需依靠边线区分层级。

#### 间距（Spacing）

- **用途与选择**：统一模块、内容、字段和操作之间的留白。
- **结构与视觉**：375px 基准：首页卡片左右各 10px、模块之间约 10px；常规页面内边距 16px，弹窗正文 20px。常用内容间距为 4 / 8 / 12 / 16 / 20 / 24 / 32px。
- **状态与交互**：间距随内容排版保留；隐藏模块后同时移除多余间隙。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：窄屏先换行再调整布局，不挤压文字或点击热区。

#### 分割线（Divider）

- **用途与选择**：分隔列表条目、表单分组和说明区；优先通过留白建立层级。
- **结构与视觉**：1px #EDF0F4；优先使用缩进分隔，避免穿过头像和图标。
- **状态与交互**：分割线本身不响应点击，不显示可操作状态。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：末项避免重复底线；深色、缩放和高对比度下仍可辨认分组。

#### 骨架屏（Skeleton）

- **用途与选择**：首次加载时预示头像、标题和正文结构。
- **结构与视觉**：沿用内容结构，图片、标题与正文分别占位；加载完成后替换，不覆盖已有内容。
- **状态与交互**：加载完成后替换为内容；刷新已有内容时优先保留原列表。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：失败后结束骨架并显示重试；空数据切换空状态，不持续占位。

#### 系统导航 · 五列入口（SystemGrid）

- **用途与选择**：展示已配置的业务系统入口，适合五列快捷访问。
- **结构与视觉**：系统导航、我的系统、全部系统均为 5 列；首页每页 5 个，图标 34px、文字 13/20，左右滑动、分页按钮与键盘方向键联动；分页红条12×3px、灰条6×3px，间距4px，全圆角。
- **状态与交互**：支持横滑、分页按钮及方向键；点击入口进入对应系统。
- **无障碍与焦点**：分页和入口可 Tab 聚焦；左右方向键切换页，Enter 打开入口。

- **边界与恢复**：窄屏宽度不超过 80%；长菜单内部滚动，关闭后恢复原页面位置。

#### 多行文本（Textarea）

- **用途与选择**：填写说明、意见和较长的多行内容。
- **结构与视觉**：正文 14 / 22，默认白底，悬停或聚焦时 #FCFCFE 浅灰底；支持字数提示与内容换行，不阻止正常粘贴；点击和聚焦不显示蓝色外描边。
- **状态与交互**：输入实时更新字数；默认白底，hover / 聚焦浅灰，允许正常换行。
- **无障碍与焦点**：Enter 换行；保留输入法组合、复制粘贴，Tab 切换控件。
- **边界与恢复**：字数上限明确提示；长内容内部滚动或自增高，校验失败保留文本。

#### 搜索框（Search）

- **用途与选择**：对联系人或列表执行关键词筛选。

- **状态与交互**：输入即筛选，清空后恢复结果；无结果显示关键词与恢复入口。
- **无障碍与焦点**：输入可 Tab 聚焦；清空按钮可键盘操作，清空后焦点回到输入框。
- **边界与恢复**：异步结果防止旧请求覆盖新关键词；网络失败与无结果分别说明。

#### 单选（Radio）

- **用途与选择**：同一问题只能选择一个答案，如审批方式。
- **结构与视觉**：同组只选一项；整行可点，选择状态不只依赖颜色。
- **状态与交互**：整行点击切换，选择新项时取消原项。
- **无障碍与焦点**：同组原生单选通过方向键切换，Tab 进入或离开组。
- **边界与恢复**：至少有一个有效选项；禁用项不能被选中，必填时明确校验。

#### 多选（Checkbox）

- **用途与选择**：订阅内容等允许同时选择多项的独立选项。
- **结构与视觉**：复选框为 18px 方框、4px 圆角；选中红底白色勾选，支持多项及取消。
- **状态与交互**：点击勾选或取消；整行标签可点，状态同时以勾选符号表达。
- **无障碍与焦点**：Tab 定位，Space 切换；原生复选框保留可见焦点。
- **边界与恢复**：全选需处理中间状态；必选数量限制就近提示，保留已有选择。

#### 开关（Switch）

- **用途与选择**：立即生效的二元设置，如消息免打扰。
- **结构与视觉**：立即生效的二元设置；品牌红开启与灰色关闭。
- **状态与交互**：切换后更新开启状态；异步保存期间避免重复切换。
- **无障碍与焦点**：Tab 定位，Enter / Space 切换；辅助技术应读出开关状态。
- **边界与恢复**：保存失败恢复原值并提示；需要提交确认的选项改用复选框。

#### 普通选择器（Picker）

- **用途与选择**：从固定少量选项中单选，如处理优先级。
- **结构与视觉**：高度统一 40px，固定少量选项使用选择器；默认白底，悬停、点击/展开或键盘聚焦时使用 #FCFCFE 浅灰底；下拉面板统一白底、1px #E7ECF5 描边、12px 圆角及轻阴影，支持键盘选择和 Escape 取消。
- **状态与交互**：默认白底，hover / 聚焦 / 展开浅灰；选中后关闭，Escape 取消本次浏览。
- **无障碍与焦点**：方向键移动、Home / End 到首尾、Enter 确认、Escape 关闭并回焦。
- **边界与恢复**：禁用选项不能选；长列表内部滚动，无结果保留当前有效值。

#### 级联选择器（Cascader）

- **用途与选择**：按组织与部门等层级逐步选择路径。
- **结构与视觉**：各级选择器高度统一 40px；默认白底，悬停、点击/展开或键盘聚焦时使用 #FCFCFE 浅灰底；切换上级后重置不兼容的下级选项，保持路径可读。
- **状态与交互**：改变上级后重置不兼容下级；当前路径完整可读。
- **无障碍与焦点**：每级沿用选择器的方向键、确认与 Escape；Tab 顺序按层级排列。
- **边界与恢复**：下级未加载或无数据时显示明确状态；失败重试不丢失上级选择。

#### 城市选择器（CityPicker）

- **用途与选择**：省、市等地区联动选择，提交结构化地区信息。
- **结构与视觉**：省 / 市选择器高度统一 40px；默认白底，悬停、点击/展开或键盘聚焦时使用 #FCFCFE 浅灰底；联动选择完成后显示完整地区。
- **状态与交互**：更换省份后更新城市列表；完成后展示完整地区名称。
- **无障碍与焦点**：沿用选择器键盘规则；省、市按填写顺序聚焦。
- **边界与恢复**：直辖市、空城市和地区变更需处理；无效旧值提示重新选择。

#### 日期时间选择器（DatePicker）

- **用途与选择**：日程与表单中的日期、时间输入。
- **结构与视觉**：日期时间输入高度统一 40px，沿用日程表单；默认白底，悬停、点击/展开或键盘聚焦时使用 #FCFCFE 浅灰底；开始早于结束，日期与时间使用本地时区；点击和聚焦不显示蓝色外描边。
- **状态与交互**：默认白底，hover / 聚焦 / 展开浅灰；选择后更新可读时间。
- **无障碍与焦点**：沿用系统日期控件键盘方式；Tab 进入字段，Escape 退出日期面板。
- **边界与恢复**：校验开始早于结束；处理空值、非法日期、跨日及时区变化。

#### 滑块（Slider）

- **用途与选择**：在连续或有固定步长的范围内选择值，如音量。
- **结构与视觉**：展示当前值；支持拖动、键盘调整及明确范围。
- **状态与交互**：拖动即时显示当前值；设置最小、最大和步长。
- **无障碍与焦点**：方向键按步长调整，Home / End 到边界；值变化可被读屏感知。
- **边界与恢复**：超范围值归一到合法范围；精确输入需求同时提供数字输入。

#### 步进器（Stepper）

- **用途与选择**：在有限范围内逐步调整数量。
- **结构与视觉**：加减按钮 44px 热区；达到上下限时禁用。
- **状态与交互**：点击加减更新数量，达到边界禁用对应按钮。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：不允许越界或重复请求造成跳数；无效输入恢复到最近合法值。

#### 文件上传（Upload）

- **用途与选择**：为表单或消息附加文件和图片，选择后先确认内容。
- **结构与视觉**：显示已选文件名与移除操作；图片支持预览，选择后不会自动发送。
- **状态与交互**：展示文件名、图片预览和移除入口；选择不会自动发送。
- **无障碍与焦点**：选择文件与移除按钮可键盘激活；使用系统文件选择面板。
- **边界与恢复**：类型、大小与数量限制提前说明；取消选择保留原列表，失败允许重试。

#### 标签选择（Chip）

- **用途与选择**：将少量可选标签直接展开，便于快速选择。
- **结构与视觉**：标签高度统一 40px；单选或多选需明确，选中状态同时提供边框和勾选。
- **状态与交互**：单选互斥，多选可取消；用边框、勾选和文字共同表达状态。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：长标签允许换行；数量过多时改用选择器，禁用项说明原因。

### 6. 内容展示

卡片、列表和空状态使用已有的白底、圆角与文字层级。

| 组件 | 英文 |
| --- | --- |
| 卡片 | Card |
| 列表 | List / ListItem |
| 头像 | Avatar |
| 徽章 | Badge |
| 标签 | Tag |
| 轮播 | Swiper / Carousel |
| 空状态 | Empty |
| 结果页 | Result |
| 进度条 | Progress |
| 倒计时 | CountDown |
| 折叠面板 | Collapse |
| 图片预览 | ImageViewer |
| 公告栏 | NoticeBar |

#### 卡片（Card）

- **用途与选择**：组织相关内容和操作，如资讯、简报或指标模块。
- **结构与视觉**：首页普通卡片为白底、16px 圆角；标题 16/24、600，配橙色渐变竖条，更多位于右侧。常用功能和系统导航专用 70% 白底毛玻璃；内容高度随数据自适应。
- **状态与交互**：仅有跳转职责时整卡可点；含多个操作时分别设置入口。
- **无障碍与焦点**：可操作内容按阅读顺序聚焦；静态卡片不增加 Tab 停靠点。
- **边界与恢复**：内容高度自适应；图片失败保留文字，空模块说明原因或收起。

#### 列表（List / ListItem）

- **用途与选择**：展示联系人、通知和业务记录等同构条目。
- **结构与视觉**：主标题 16 / 24，辅助 12 / 18；整行点击，操作区域独立。
- **状态与交互**：整行进入详情，尾部操作独立响应，不连带触发行点击。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：长标题换行或省略；加载、空、错误和末页有各自反馈。

#### 头像（Avatar）

- **用途与选择**：识别人、群组或 AI 数字员工。
- **结构与视觉**：使用通讯录头像；常用 32 / 40 / 48px，避免拉伸。
- **状态与交互**：静态头像不交互；可进入资料时提供明确入口与按下反馈。
- **无障碍与焦点**：静态图像不聚焦；资料入口可用键盘激活，并读出对象名称。
- **边界与恢复**：图片加载失败使用姓名或默认头像；保持比例且不暴露损坏图片。

#### 徽章（Badge）

- **用途与选择**：显示未读数或需要关注的状态提示。
- **结构与视觉**：42px浅灰圆角方块，右上角计数胶囊高20px、最小宽28px、左右6px、12/16常规字重、2px白边；红点外径10px含1px白边，统一主题红；0默认隐藏，超过99显示99+。
- **状态与交互**：数量随已读状态变化；仅附着在对应业务入口上。
- **无障碍与焦点**：徽章自身不聚焦；父入口名称应包含未读数量或状态。
- **边界与恢复**：零值按业务隐藏；负数归零，超过 99 显示 99+，不撑开入口。

#### 标签（Tag）

- **用途与选择**：以紧凑标签标记已完成、待审批、进行中、告警和未完成。
- **结构与视觉**：状态标签：12/18、600字重、4px圆角、上下2px/左右6px；覆盖已完成、待审批、进行中、告警、未完成，成功、警告、信息、告警和中性状态使用对应浅色背景与语义色。
- **状态与交互**：静态状态不响应点击；筛选标签应使用独立的可选择控件。
- **无障碍与焦点**：静态展示不进入 Tab 顺序；相关说明可选择、复制。
- **边界与恢复**：未知状态显示中性文字；状态不只依赖颜色，不把告警与待审批混用。

#### 轮播（Swiper / Carousel）

- **用途与选择**：以海报案例说明轮播；入口轮播另沿用业务分页样式。
- **结构与视觉**：门户海报包含5个案例，支持左右滑动、圆点切换及点击查看案例；海报圆点为白色。常用功能与系统入口另用红色12×3px选中胶囊、灰色6×3px未选中胶囊，间距4px，均为全圆角。
- **状态与交互**：横滑与圆点联动，点击海报进入案例；页码与当前内容同步。
- **无障碍与焦点**：圆点可键盘激活；若业务自动轮播，需提供暂停并支持减少动态效果。
- **边界与恢复**：单项隐藏无意义分页；图片失败保留标题，末项行为需保持一致。

#### 空状态（Empty）

- **用途与选择**：列表或搜索没有记录时解释原因，并给出下一步操作。
- **结构与视觉**：使用提供的 100×100px 透明底空状态插画，说明原因并提供下一步操作。
- **状态与交互**：操作按钮引导新建、刷新或重置筛选；空状态不自动消失。
- **无障碍与焦点**：插画不聚焦；恢复操作可 Tab 激活，说明可被读屏读取。
- **边界与恢复**：区分首次无数据、筛选无结果与请求失败，不以空状态掩盖错误。

#### 结果页（Result）

- **用途与选择**：完整反馈成功、失败等流程结果。
- **结构与视觉**：反馈操作结果，提供返回或继续操作，不使用空泛提示。
- **状态与交互**：显示具体结果、必要原因和返回或继续操作入口。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：失败保留已填内容与重试路径；返回不重复提交原请求。

#### 进度条（Progress）

- **用途与选择**：展示可度量的上传、处理或任务完成进度。
- **结构与视觉**：展示百分比与进度条；完成后切换成功语义。
- **状态与交互**：百分比与进度条同步；完成后切换成功状态。
- **无障碍与焦点**：进度本身不聚焦；使用 progressbar 语义与当前值，避免逐帧播报。
- **边界与恢复**：无法测量时使用不定进度；失败、取消与停滞不能显示为已完成。

#### 倒计时（CountDown）

- **用途与选择**：展示有明确结束时间的短时等待或活动倒计时。
- **结构与视觉**：按秒更新，页面切换时清理计时器；提供重新开始。
- **状态与交互**：按秒更新；到零停止，提供重新开始入口。
- **无障碍与焦点**：输出按需读屏提示，避免每秒打断；重新开始按钮可键盘操作。
- **边界与恢复**：从后台恢复后按目标时间校正；离开页面后停止计时，禁止显示负数。

#### 折叠面板（Collapse）

- **用途与选择**：将次要或较长内容按标题分组收起。
- **结构与视觉**：整行标题可点，展开状态通过箭头方向与可访问状态表达。
- **状态与交互**：点击标题展开或收起；箭头与展开状态同步更新。
- **无障碍与焦点**：标题使用按钮，可 Tab 定位、Enter / Space 切换。
- **边界与恢复**：长标题换行；收起前若焦点位于内容中，需回到标题按钮。

#### 图片预览（ImageViewer）

- **用途与选择**：查看聊天和资讯中的大图，提供缩放与退出。
- **结构与视觉**：沿用聊天图片预览；支持缩放、双指操作、关闭和键盘返回。
- **状态与交互**：支持缩放按钮、双指缩放及关闭；图片保持比例。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：加载失败显示重试；缩放限制在合理范围，关闭后恢复原页面滚动。

#### 公告栏（NoticeBar）

- **用途与选择**：持续展示简短重要公告，并引导查看完整内容。
- **结构与视觉**：单行重要通知，提供查看入口；减少动态效果时使用静态文字。
- **状态与交互**：点击查看入口进入详情；动态滚动信息需可暂停。
- **无障碍与焦点**：查看入口可键盘激活；减少动态效果时改为静态显示。
- **边界与恢复**：超长文案不截断关键意思；公告过期后由业务移除。

### 7. 反馈弹窗

轻反馈不打断操作，需要决定的事项使用弹窗。

| 组件 | 英文 |
| --- | --- |
| 提示气泡 · 五种指向 | Bubble |
| 轻提示 | Toast |
| 确认弹窗 | Dialog |
| 动作面板 | ActionSheet |
| 下拉菜单 | Dropdown |
| 顶部通知 | Banner |
| 遮罩层 | Overlay |
| 引导蒙层 | Guide |
| 加载 | Loading |

#### 提示气泡 · 五种指向（Bubble）

- **用途与选择**：在目标附近补充简短提示，五种指向适应不同边缘。
- **结构与视觉**：白底提示气泡主体高 32px（不含三角），8px 圆角、轻阴影、正文 14/22、左右内边距 12px；8px 箭头支持左下、右下、左上、右上及底部居中，箭头距圆角至少 12px；不遮挡触发控件或重要内容。
- **状态与交互**：随触发状态显示，避免遮挡目标；交互内容较多时改用气泡面板。
- **无障碍与焦点**：由聚焦或显式按钮触发，并支持 Escape 关闭；辅助技术应能读取关联提示。
- **边界与恢复**：靠近视口边缘时调整方向；长说明换用可换行面板，不挤入 32px 单行框。

#### 轻提示（Toast）

- **用途与选择**：提供文字、加载、信息、成功、警告、错误六种轻提示，用于操作反馈、语义消息与短暂等待。
- **结构与视觉**：包含文字、加载、信息、成功、警告、错误六种效果；统一白底、1px #EBEEF5细描边、12px圆角与轻阴影，正文14/22、高度至少48px，无关闭按钮。文字提示不带图标，信息/成功/警告/错误分别配20px蓝/绿/橙/红语义图标，约2.5秒自动消失；加载提示使用20px红色渐变转圈，任务结束后更新或关闭。
- **状态与交互**：文字及四种语义提示约2.5秒自动消失；加载提示随任务结束更新或关闭。新消息替换当前提示，不显示关闭按钮。
- **无障碍与焦点**：使用读屏播报且不抢焦点；文字提示不带图标，语义提示使用文字配合对应颜色图标，加载提示展示红色渐变转圈并说明加载状态，尊重减少动态效果。
- **边界与恢复**：长文案自然换行且保持屏幕内显示；加载失败应结束等待并呈现原因，关键错误持续就近展示。

#### 确认弹窗（Dialog）

- **用途与选择**：有标题或无标题提示用于需要确认阅读的信息；确认弹窗用于明确决定，圆角按钮用于突出主动作，组件用法支持自定义图片内容。
- **结构与视觉**：包含有标题提示、无标题提示、确认弹窗、圆角按钮样式、异步关闭和自定义内容。白底、16px圆角、基准宽320px，标题居中18/26、600，正文14/22；基础操作栏48px高，基础确认按钮使用功能蓝；圆角按钮主体36px并保留44px热区，圆角确认按钮使用品牌渐变。
- **状态与交互**：提示弹窗仅提供确认；确认弹窗提供取消与确认。异步提交中禁用确认，完成后关闭；取消、点击遮罩或按返回键退出时中止等待。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：窄屏保持两侧留白，长内容内部滚动；真实业务报错应保留弹窗与输入并提供重试，禁止重复提交。

#### 动作面板（ActionSheet）

- **用途与选择**：在移动端底部展示少量上下文操作；按场景选择基础列表、图标列表、取消分组、描述信息、选项状态或自定义内容。
- **结构与视觉**：包含基础用法、图标选项、取消按钮、描述信息、选项状态与自定义面板。白底、顶部22px圆角；选项至少56px高、16/24正文，图标20px；面板描述14/22、选项描述12/18，取消按钮52px高，以8px灰色间隔分组。禁用浅灰、加载红色渐变、危险选项红色。
- **状态与交互**：点击可用选项后反馈并关闭；禁用与加载项不执行操作。取消独立分组，点击遮罩或按返回键均可退出；自定义面板支持文档预览及分享入口。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：长列表内部滚动，保留底部安全区；禁用和加载状态同时由语义表达，危险操作执行前按风险确认。

#### 下拉菜单（Dropdown）

- **用途与选择**：在入口附近展示当前视图或操作选项。
- **结构与视觉**：紧邻触发入口，选中后更新当前项并关闭。
- **状态与交互**：展开菜单，选择后更新当前值并关闭；外部点击或 Escape 取消。
- **无障碍与焦点**：菜单应支持方向键、Enter 选择与 Escape 退出；关闭回焦。
- **边界与恢复**：禁用项不可选；空间不足改为向上展开或在面板内滚动。

#### 顶部通知（Banner）

- **用途与选择**：页面顶部以基础通知条持续呈现信息、成功、警告或错误。
- **结构与视觉**：通栏浅色底通知条，无圆角、描边及阴影；正文14/22，通知条高40px、单行显示且长文省略，左侧18px语义图标，右侧灰色关闭按钮保留44px热区。信息蓝#006DFF、成功绿#00B578、提醒橙#FF7D00、错误红#FF0000，文字与图标同色，底色为对应语义色8%混白；每条独立关闭，支持恢复全部。
- **状态与交互**：每条可独立关闭，重要消息不按计时自动消失。
- **无障碍与焦点**：关闭按钮可通过辅助操作激活；新消息按紧急程度播报，不抢焦点或重复打断。
- **边界与恢复**：保持40px单行，超长文字省略且保留完整内容供辅助技术读取；关闭不影响其他消息，关闭按钮独立保留44px热区，关键阻断问题保留恢复入口。

#### 遮罩层（Overlay）

- **用途与选择**：隔离弹窗、抽屉和底部面板与背景页面。
- **结构与视觉**：业务底部弹层使用 #131928、40% 遮罩及 2px 背景模糊；阻止背景操作、限制弹层内部焦点，支持关闭按钮和 Escape。
- **状态与交互**：打开时阻止背景操作与滚动；按业务允许遮罩关闭。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：多层浮层按顺序关闭；退出后恢复原滚动与焦点，不遗留锁定。

#### 引导蒙层（Guide）

- **用途与选择**：首次进入功能时介绍关键入口与操作顺序。
- **结构与视觉**：首次使用时突出关键入口；提供说明、跳过与关闭。
- **状态与交互**：突出当前目标，支持下一步、跳过与关闭；不强迫完成全部引导。
- **无障碍与焦点**：打开后焦点进入浮层并限制在内部；Escape 关闭，关闭后回到触发入口。
- **边界与恢复**：目标不可见时先定位或跳过；小屏说明不遮挡目标与退出按钮。

#### 加载（Loading）

- **用途与选择**：反馈正在处理、暂时无法展示内容的状态。
- **结构与视觉**：浅底加载图标使用浅红至品牌红 #FF0000 的渐变旋转指示，配合文字；耗时操作允许取消，失败保留重试路径。
- **状态与交互**：旋转指示配明确文字；长任务提供取消，结束后切换实际结果。
- **无障碍与焦点**：通过读屏反馈加载状态；取消按钮可聚焦，不在计时更新时反复抢焦点。
- **边界与恢复**：失败结束加载并给出重试；页面退出时取消请求或忽略过期返回。

### 8. 移动交互

手势操作均提供按钮替代，状态变化需要可感知反馈。

| 组件 | 英文 |
| --- | --- |
| 下拉刷新 | PullToRefresh |
| 上拉加载更多 | InfiniteScroll |
| 侧滑单元格 | SwipeAction |
| 吸顶 | Sticky |

#### 下拉刷新（PullToRefresh）

- **用途与选择**：在列表顶部主动重新获取最新内容。
- **结构与视觉**：在列表顶部向下拖动约 60px 触发；显示释放、加载与完成状态。
- **状态与交互**：下拉达到约 60px 后释放触发；加载中禁止重复刷新。
- **无障碍与焦点**：提供“刷新”按钮替代手势，Enter / Space 可触发。
- **边界与恢复**：仅在列表顶部拦截下拉；失败保留原内容和重试，避免与页面滚动冲突。

#### 上拉加载更多（InfiniteScroll）

- **用途与选择**：长列表按页加载后续记录，减少首屏等待。
- **结构与视觉**：到达列表底部加载下一组；加载中禁止重复触发，无更多时明确提示。
- **状态与交互**：触底或点击加载更多；加载期间不重复请求，无更多时明确说明。
- **无障碍与焦点**：始终提供可聚焦的加载按钮；新增记录不强制移动焦点。
- **边界与恢复**：失败保留已加载条目并重试当前页；避免重复项和旧请求乱序。

#### 侧滑单元格（SwipeAction）

- **用途与选择**：为列表条目提供删除等低频辅助操作。
- **结构与视觉**：左滑显示删除，提供展开按钮替代；删除后允许撤销。
- **状态与交互**：左滑只展开操作；点击删除执行，完成后允许撤销。
- **无障碍与焦点**：提供“更多”按钮替代侧滑；展开后的删除按钮可键盘操作。
- **边界与恢复**：纵向滚动时不误触删除；同一时间只展开一项，失败恢复原条目。

#### 吸顶（Sticky）

- **用途与选择**：滚动中保留当前分组标题或筛选条件。
- **结构与视觉**：分组标题在容器内吸顶，不盖住导航和可操作内容。
- **状态与交互**：仅在所属容器内吸顶，后续分组按顺序替换。
- **无障碍与焦点**：吸顶本身不改变焦点；标题内操作保持原有 Tab 顺序。
- **边界与恢复**：不盖住导航、锚点目标或操作；容器底部结束吸顶。

### 9. 配套规范

尺寸、适配、手势与组件状态共同构成移动端验收标准。

| 组件 | 英文 |
| --- | --- |
| 触摸热区 | Touch Target |
| 适配与横竖屏 | Responsive |
| 手势规范 | Gesture |
| 组件状态 | States |

#### 触摸热区（Touch Target）

- **用途与选择**：统一触屏操作可点击范围，避免小图标难以命中。
- **结构与视觉**：操作热区至少44×44px；图标本身可以更小。
- **状态与交互**：视觉主体可以小于热区；相邻热区不重叠、不误触。
- **无障碍与焦点**：Tab 定位操作，Enter / Space 激活；保留清晰的键盘焦点。
- **边界与恢复**：窄屏和缩放后仍保持至少44×44px；边缘热区不能超出容器。

#### 适配与横竖屏（Responsive）

- **用途与选择**：在手机不同屏幕宽度与横竖屏中保持一致的信息与操作顺序。
- **结构与视觉**：375px 基准；320 / 375 / 430px 检查内容与热区，横屏允许内容滚动。
- **状态与交互**：375px 为基准；宽度变化调整布局，内容区域保持可滚动。
- **无障碍与焦点**：缩放、旋转和键盘弹起不改变焦点顺序；聚焦项应保持可见。
- **边界与恢复**：检查 320 / 375 / 430px 与横屏；长内容不产生页面横向溢出。

#### 手势规范（Gesture）

- **用途与选择**：为点击、长按、侧滑、下拉和双指缩放建立一致约定。
- **结构与视觉**：点击、长按、侧滑、下拉、双指缩放均需反馈，并提供无手势的替代操作。
- **状态与交互**：达到明确阈值再触发；拖动与滚动冲突时优先保证页面可滚动。
- **无障碍与焦点**：所有手势提供按钮或键盘等价操作；不能要求用户必须长按或双指。
- **边界与恢复**：取消手势时复位；多点触控、移出边界和中途松手不误执行动作。

#### 组件状态（States）

- **用途与选择**：作为组件默认、按下、禁用、加载、错误、成功和空状态的验收标准。
- **结构与视觉**：覆盖默认、点击、禁用、加载、报错；浅底加载图标使用浅红至品牌红 #FF0000 的渐变，成功和空状态同样给出下一步操作。
- **状态与交互**：禁用不响应，加载不重复提交，错误就近反馈，成功后提供下一步。
- **无障碍与焦点**：保持焦点可见；错误应与对应字段关联并可被读屏读取，不只依赖颜色。
- **边界与恢复**：重试不丢输入；修正后移除过期错误，空数据与加载失败分开处理。

## 状态与交互

| 状态 | 统一约定 |
|---|---|
| 默认与按下 | 可操作对象保持明确入口，点击及时反馈；静态内容不增加无意义的点击行为。 |
| 悬停与焦点 | 不依赖 hover 暴露触屏操作；按钮、链接保留键盘焦点。文本、搜索、多行文本和日期字段不显示蓝色外描边；输入和选择控件通过原有边线与浅灰背景反馈。 |
| 选中 | 业务分类与底部导航使用品牌红；顶部视图使用白底、黑色加粗；不能仅靠颜色传达选中状态。 |
| 禁用 | 阻止动作，不将禁用项加入可激活操作；加载和禁用分别表达。 |
| 加载 | 阻止重复提交，浅底转圈使用红色渐变；轻提示加载与任务生命周期绑定，耗时操作提供取消。 |
| 错误与恢复 | 就近说明原因，保留输入与可恢复路径；不将空数据伪装为加载失败。 |
| 完成与空状态 | 文字轻提示约2.5秒消失；需要决定的操作使用 Dialog，空状态说明原因并提供下一步。 |

- 浮层打开后限制背景操作并管理内部焦点；支持的关闭方式包括明确按钮、遮罩和 Escape，关闭后回到触发入口。
- 所有手势提供按钮或键盘替代：分页、缩放、更多、刷新等入口必须可访问。
- 减少动态效果设置下，停止非必要旋转和动画，使用静态文字表达当前状态。
- 320 / 375 / 430px及横屏均检查可读性、滚动和至少44×44 px点击热区。
