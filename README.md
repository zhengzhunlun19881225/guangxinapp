# 广智新 App 独立开发包

基于 Figma 文件「规范」的 `app` 页面（0:4807），还原 11 张移动端画布。此目录包含独立前端源码、原始设计资源、生产构建、设计来源及浏览器验收截图。

已按最新提供的移动端规范统一品牌与功能色、文字颜色、字号、行高和字重，以 **375px** 为设计基准。完整规则见 `mobile-design-spec.md`，统一样式入口为 `src/mobile-spec.css`，跨页面间距由 `src/page-spacing.css` 统一管理。

- 全新访问地址：<http://localhost:5317/>
- 全部画布入口：<http://localhost:5317/#/canvases>
- 手机规范入口：<http://localhost:5317/#/mobile-spec>，完整覆盖9类、71项组件和4项基础规范，支持分类、搜索与交互示例；页面顶部可下载完整 App 设计规范 MD 文档，涵盖基础样式与全部组件的用途、视觉、交互、无障碍和边界规则；下载文件不包含源码、接入、预览或构建维护说明。
- IM / 通讯录二级页面：从原有会话、联系人、「我的群组」、企业通讯录和右上角加号进入；快速预览群组页：<http://localhost:5317/#/im-groups?origin=contacts>。
- 本次项目未修改其他项目；代码与运行依赖均在当前目录独立管理。
- 技术栈：React 19、TypeScript、Vite 8、Tailwind CSS 4。

## 在线体验

[广智新 App](https://zhengzhunlun19881225.github.io/guangxinapp/) 由 GitHub Pages 提供。推送到 `main` 后，GitHub Actions 会构建并发布。

## 直接预览

已提供生产构建 `dist/`。安装 Node.js 22.12+ 后，双击「启动App预览.command」，或运行：

```sh
node scripts/serve.mjs
```

打开 <http://localhost:5317/>。如果端口已被当前开发预览占用，直接访问该地址即可。也可以用 `PORT=5318 node scripts/serve.mjs` 指定新端口。

## 继续开发

```sh
npm install
npm run dev
```

也可使用 pnpm，目录内提供锁文件 `pnpm-lock.yaml`：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

`build` 先从在线规范的目录、App设计说明与基础样式生成完整 MD 文档，再运行 TypeScript 检查并生成生产构建。`pnpm build:spec` 可单独更新文档；基础说明位于 `docs/mobile-spec-foundations.md` 和 `docs/mobile-spec-interactions.md`，生成结果为 `mobile-design-spec.md` 与可下载的 `public/mobile-design-spec.md`。每个画布按路由独立加载。桌面预览保留移动端画布，在手机上适配可用宽度与屏幕高度；底部导航固定在可见区域。
